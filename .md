### 0.3 Motion architecture (`src/styles/motion.js`, Phase 3)
```js
// src/styles/motion.js — spring presets (Apple damping/response -> motion bounce/duration, §4)
export const spring = {
  default: { type: 'spring', bounce: 0,   duration: 0.4  }, // damping 1.0 / response 0.4 — reposition, reveals
  snappy:  { type: 'spring', bounce: 0,   duration: 0.3  }, // nav pill, toasts, accordion
  sheet:   { type: 'spring', bounce: 0.2, duration: 0.35 }, // drawer/sheet — Apple ships 0.8/0.3
  momentum:{ type: 'spring', bounce: 0.2, duration: 0.4  }, // post-flick only (§4: bounce only after momentum)
};
export const fadeTransition = { duration: 0.2, ease: 'easeOut' }; // reduced-motion fallback (§14)

// §6 — Apple's exponential-decay projection (NOT v²/2a)
export function project(velocity, rate = 0.998) {
  return (velocity / 1000) * rate / (1 - rate);
}
// §9 — rubber-band for overdrag
export function rubberband(overshoot, dimension, constant = 0.55) {
  return (overshoot * dimension * constant) / (dimension + constant * Math.abs(overshoot));
}
```
Rules: springs for anything gesture-driven or entering/exiting (drawer, modal, toasts, pill, accordion, reveals); CSS transitions only for hover/press states; **every motion component calls `useReducedMotion()` and swaps to opacity-only variants with `fadeTransition`** (§14). Only `transform`/`opacity` animated (§11).
